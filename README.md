# Rocket League – Mini-Spiel

Ein kleines, eigenständiges Rocket-League-inspiriertes Top-Down-Spiel im Browser (HTML Canvas, keine Abhängigkeiten).

## Spielen

`index.html` im Browser öffnen. Auf Mobilgeräten oder wenn die Gamepad-API lokal nicht verfügbar ist, kann die Seite über einen lokalen Webserver geöffnet werden.

## Steuerung

- **Tastatur:** W/Pfeil hoch = Gas, S/Pfeil runter = Rückwärts, A/D bzw. Pfeile links/rechts = Lenken, Shift = Boost, R = Ball und Auto zurücksetzen.
- **Controller (Gamepad API):** linker Stick = Lenken, RT bzw. A = Gas, LT bzw. B = Rückwärts, X bzw. rechter Bumper = Boost. Controller im Browser verbinden und eine Taste drücken, falls er nicht sofort erkannt wird.

Controller-Unterstützung hängt vom Browser und Betriebssystem ab. Die Gamepad API funktioniert in der Regel auf HTTPS oder localhost.
